Qué es esta herramienta y cómo funciona la sincronización con Neon

Este cuaderno permite recopilar notas, meditaciones, referencias cruzadas y cadenas temáticas fundamentadas en las Santas Escrituras y las publicaciones de la Biblioteca en línea Watchtower (wol.jw.org). Cuando se ejecuta en línea se conecta a Neon Postgres (base de datos serverless en la nube); cuando se usa localmente o sin conexión, almacena los datos de forma instantánea y persistente en su navegador.

El endpoint serverless de esta aplicación (/api/notes) ejecuta transacciones SQL directas sobre Neon Postgres mediante el cliente oficial @neondatabase/serverless con soporte para WebSocket y HTTP connection pooling. En caso de no haber conexión de red, la aplicación conmuta automáticamente al almacenamiento local seguro del navegador.
