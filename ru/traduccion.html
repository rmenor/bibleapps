Как устроена система перевода в библейских приложениях?

Чтобы любой желающий мог помочь с переводом или улучшением текстов без необходимости разбираться в программировании, весь контент, заголовки, описания и исторические данные вынесены в отдельные файлы. Переводчик редактирует только текст на своем языке, сохраняя исходную техническую логику каждого приложения.

Как перевести приложение из пакета?

Процесс устроен максимально просто и прозрачно. Вам не нужно устанавливать сложные программы или компилировать код, если вы этого не хотите.

1

Децентрализованная архитектура приложений

Каждое приложение является полностью автономным и независимым. Переводы находятся внутри каждого приложения в папке apps/{app}/locales/:

  • apps/medidas/locales/ — Библейские меры, веса и монеты
  • apps/atlas/locales/ — Библейские места, маршруты и 12 племён
  • apps/cronologia/locales/ — Хронология, цари, пророки и эпохи
2

Выберите приложение и язык

Каждая папка locales/ содержит базовый файл es.json, существующие переводы (напр., ru.json), шаблон _template.json и файл INSTRUCCIONES.md:

  • Режим JSON: Редактируйте файл нужного языка в выбранном приложении.
  • Полная автономия: Можно переводить одно приложение независимо от других.
3

Сверяйтесь с wol.jw.org

Главное правило: Никогда не переводите библейские имена собственные, древние меры и названия книг дословно.

  • Всегда проверяйте словарную статью в энциклопедии «Понимание Писания» на вашем языке на wol.jw.org.
  • Используйте официальный «Перевод нового мира».
4

Динамическая загрузка в index.html

При добавлении или обновлении языка:

  • Файл index.html каждого приложения динамически загружает JSON из ../locales/{lang}.json.
  • Все стили CSS вынесены в отдельные независимые .css файлы.
  • Гарантирована универсальная работа как на веб-сервере, так и локально по протоколу file://.
Хотите добавить новый язык (например, французский, немецкий, португальский)? Создайте новую языковую папку одной командой: npm run i18n:new -- --lang=fr --name="Français".

Правила библейского исследования и источники

Приложения BibleApps требуют высочайшей исторической и текстовой точности. Любой факт или термин должен основываться исключительно на онлайн-библиотеке wol.jw.org.

Строгий запрет: спекулятивные светские источники Категорически запрещено использовать Википедию, общие словари, форумы или автоматический машинный перевод для библейских терминов и хронологии.
Категория Обязательный источник (wol.jw.org) Указание для переводчика
Топонимы и география (Атлас) «Понимание Писания» (it-1 / it-2) и брошюра «Увидим добрую землю» Используйте каноническое написание из «Перевода нового мира» на вашем языке (напр., Сузы, Мегиддо, Хеврон).
Меры, веса и монеты (Меры) «Понимание Писания», статья «Меры и весы» Метрические значения универсальны (локоть ≈ 44,5 см; бат ≈ 22 л), но название единицы должно строго соответствовать энциклопедии (исп. Codo; рус. Локоть; англ. Cubit).
Хронология и персоналии (Хронология) «Понимание Писания», статьи «Хронология», «Цари», «Пророк» Точно соблюдайте даты до н. э. / н. э. (Сотворение Адама 4026 г. до н. э., Потоп 2370 г. до н. э., Исход 1513 г. до н. э., Опустошение Иерусалима 607 г. до н. э. и др.).
Рукописи и кодексы (История) «Понимание Писания» и книга «Всё Писание вдохновлено Богом» Используйте общепринятые официальные названия (напр., Синайский кодекс, Александрийский кодекс, Папирус Честера Битти).

Структура файла перевода (JSON)

Каждый файл содержит понятные пары данных с оригиналом, переводом и пояснением контекста.

JSON 
{
  "_meta": {
    "language": "ru",
    "language_name": "Русский",
    "app": "medidas"
  },
  "ui": {
    "app_title": {
      "source": "Conversor de Pesas, Medidas y Monedas Bíblicas",
      "translation": "Конвертер библейских мер, весов и монет",
      "context": "Главный заголовок H1 приложения"
    },
    "reset_button": {
      "source": "Restablecer",
      "translation": "Сбросить",
      "context": "Кнопка сброса в калькуляторе (до 16 символов)"
    }
  },
  "data": {
    "units": {
      "codo": {
        "name": {
          "source": "Codo",
          "translation": "Локоть",
          "context": "Единица длины. См. «Понимание Писания», статья «Локоть»"
        },
        "description": {
          "source": "Distancia desde el codo hasta el dedo medio (~44,5 cm).",
          "translation": "Расстояние от локтя до конца среднего пальца (~44,5 см).",
          "context": "Каноническое определение из энциклопедии"
        }
      }
    }
  }
}

Важные правила при переводе

1. Редактируйте только "translation"

Не изменяйте ключи (такие как "app_title"), поле "source" или поле "context". Иначе система не сможет связать перевод с интерфейсом.

2. Сохраняйте HTML-теги

Если в оригинале есть теги <strong>, <em> или <br>, они должны оставаться на своих местах:

Оригинал: <strong>100%</strong> fuentes verificadas
Перевод: <strong>100%</strong> проверенные источники

3. Не меняйте переменные

Если фраза содержит переменные в фигурных скобках, такие как {count} или {unit}, оставляйте их неизменными:

Оригинал: Equivale a {value} metros
Перевод: Эквивалентно {value} метрам

4. Кавычки в тексте

Внутри значений JSON двойные кавычки необходимо экранировать: \"пример\", либо использовать кавычки-«ёлочки» («пример») в соответствии с правилами языка.

Команды автоматизации для разработчиков

При локальной разработке с установленным Node.js вам доступен набор скриптов для легкого управления переводами:

Команда Описание Пример
npm run i18n:check Проверяет целостность и синтаксис всех файлов JSON в каждом приложении (apps/*/locales/). npm run i18n:check
npm run i18n:new Создает шаблоны для нового языка во всех приложениях одновременно на основе их _template.json. npm run i18n:new -- --lang=fr --name="Français"
